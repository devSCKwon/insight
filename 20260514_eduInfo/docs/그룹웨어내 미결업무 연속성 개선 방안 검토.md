본 보고서는 그룹웨어내 결재문서(원가 외주 가격결정품의서, 구매 가격결정 품의서등)의 다운로드 원본의 수정 불가 제약을 극복하고, 수작업 없는 지속 가능한 미결업무 관리를 위해 구축된 파워쿼리 기반 자동화 시스템의 구성 및 사용 방안을 제시합니다.

## 1. 미결업무 자동화 시스템 구축 완료 (~06/30)

### ① 그룹웨어 결재문서 리포트 조회 및 프로그램 추가 개발 (완료, 100%)

- **조회 대상 및 필터:** 원가 외주 가격결정품의서 및 구매 가격결정품의서내 미결여부(Y) 및 미결내용을 관리할 수 있는 서식별 결재문서 리포트 조회 구성.
- **구매팀 가격결정 품의서 프로그램 :** 시스템에서 생성하는 문서서식내에서 미결여부 및 미결대상 내용을 기입하여 관리할 수 있도록 프로그램 수정 배포 완료.
- **데이터 범위:** 일자별 다운로드 시 결재완료 문서의 실시간 전체 이력 조회 조건 설정
- 
    

### ② 파워쿼리 데이터 병합 및 자동 정제 프로세스 제안 (완료, 100%)

- **작업 대상 폴더 지정:** 지정된 공용 폴더(`업무공용폴더:\가격결정품의_관리`)에 파일 저장 시 자동 인식
  - **자동화 정제 로직:** 파워쿼리가 폴더 내 모든 파일을 통합 병합 ➔ 중복 제거 ➔ 최신 작성일 기준 내림차순 정렬 자동 처리
- **사용자 편의:** 중복 문서는 자동제거 되게 설정하여 사용자의 별도 관리 없이 데이터 원본을 사용할수 있도록 제공


### ③ 미결 및 결재 진행현황 모니터링 시트 제작 (사용자 필요시)

- **로그 고정 기능:** 사용자가 입력한 조치 내역이 행 순서 변경과 관계없이 '문서번호' 기준으로 자석 매칭 (밀림 방지)
- **선제적 모니터링:** 7일 이상 지연 시 **노란색**, 14일 이상 지연 시 **빨간색**으로 경과일 자동 색상 경보 작동 (필요시)

## 2. 일반 사용자용 실무 사용 가이드 (3-Step)

사용자는 복잡한 수식이나 파워쿼리 편집 없이, 매일 아래의 3단계 동작만 수행하면 모니터링과 기록 관리가 자동으로 완료됩니다.

### ① [1단계] 그룹웨어 다운로드 및 파일 저장

- 그룹웨어에서 가격결정 결재문서 리포트를 조회하여 엑셀 파일로 다운로드합니다.
    
- 다운로드한 파일을 이름 변경 없이 그대로 지정 폴더(`예시) 업무공용폴더:\가격결정품의_관리`)에 저장합니다. (과거 파일을 지우지 않고 계속 쌓아두어도 무방합니다.)
    

### ② [2단계] 마스터 파일 새로고침 실행

- `가격결정품의_미결관리마스터.xlsx` 파일을 엽니다.
    
- 상단 메뉴의 `[데이터] ➔ [모두 새로고침]`을 클릭하거나 단축키 `Ctrl + Alt + F5`를 누릅니다.
    
- 쿼리가 작동하여 새롭게 추가된 미결 대상 문서들이 리스트 하단에 자동으로 생성됩니다.
    

### ③ [3단계] 미결 확인 및 조치내역 입력

- 시트별로 분리된 미조치 내역, 조치진행 내역등을 확인 합니다.
- 화면에 자동으로 노출된 **`★미결(조치필요)`** 상태의 행들을 확인합니다. (필요시 사용자조건으로 제작)
- 해당 품의 건에 대한 실제 업무 조치 상황에 따라 우측 수동 입력 열에 **`[진행 상태]`**, **`[실제 반영일]`**, `[조치 내용 로그]`를 타이틀 그대로 입력합니다.
    

## 📈 업무 개선 기대 효과

- **수작업 제로화:** 매번 대상을 찾기 위해 직접 필터링하거나 VLOOKUP, 복사·붙여넣기를 반복하던 수작업이 100% 사라집니다.
    
- **이력 영구 보존:** 원본 데이터 파일이 지워지거나 행 순서가 뒤바뀌어도 사용자가 작성해 둔 소중한 조치 기록은 고유 '문서번호'를 따라가며 안전하게 보존됩니다.
    
- **마감 지연 사전 방지:** 경과일에 따른 자동 색상 경보를 통해 지연 중인 단가 반영 건을 선제적으로 찾아내어 마감 리스크를 원천 차단합니다.

- **배경**
    
    - ERP와 그룹웨어 간 기준 정보 불일치로 인한 사용자 수작업 중복 등록 공수 발생
        
    - 임직원의 근태 및 연차 정보 접근성 저하에 따른 연차 사용 편의성 제고 필요

    - 모바일 기반 챗봇 도입을 통한 임직원 연차/근태 정보 접근성 제고
        
    - 인사, 근태, 서약서 등 전사 공통 행정 프로세스의 그룹웨어 내 원스톱(One-Stop) 처리 환경 구축

## 3. 세부 실적 내용

### ① 반복 작업 최소화를 위한 ERP 연동코드 관리 기능 구축

- **개발 개요**
    
    - ERP의 마스터 데이터를 그룹웨어 내에서 직접 연계 및 관리할 수 있는 전용 인터페이스 개발
        
    - 데이터 입력 단계에서 표준 코드를 적용하여 등록 프로세스를 대폭 간소화
        
- **시스템 화면 구성 및 적용 범위 (`image_64531d_3.png` 참조)**
    
    - **연동 코드 통합 UI 구현**
        
        - 전산 담당자가 그룹웨어 내에서 연동 대상 ERP 코드를 자동 동기화할 수 있도록 구현
            
        - 예) ERP 차종 코드의 경우 매일 특정 시간 이후 그룹웨어 내 자동 동기화를 수행하여 대용량 데이터 관리 편의성 극대화
            
    - **8대 핵심 연동 코드 매핑 완료**
        
        - `ERP휴가계코드` / `ERP인사정보`: 휴가 신청 코드 자동 연계 및 그룹웨어 비사용 임직원 데이터(생산직군 포함)까지 연동
            
        - `단가구분` / `생산기술 입찰관리업체`: 원가 및 구매 연계 시스템의 기준 데이터 동기화
            
        - `월별유류대` / `ERP사업장거래정보`: 재경 부문 전표 처리 및 비용 정산 기준 수립
            
        - `ERP차종코드` / `금융기관`: 금형 및 입찰 관리의 그룹웨어 기준 코드 관리 일원화, 사업자 등록 등 재경 업무용 금융기관 데이터 정합성 관리
            
- **도입 효과**
    
    - 동일 데이터를 양방향으로 중복 수작업 입력하던 프로세스 제거 (입력 공수 $80\%$ 절감)
        
    - 휴먼 에러 차단 및 실시간 마스터 데이터 동기화로 시스템 신뢰성 대폭 향상
        

### ② 그룹웨어 사용자 질의 응답형 BOT 개발 (연차정보알리미)

- **서비스 개요**
    
    - 모바일 및 PC 그룹웨어를 통한 대화형 연차 정보 조회 서비스 구축
        
    - 사용자 시나리오 기반의 원클릭 버튼 및 직접 텍스트 입력 방식을 동시 지원
        
- **주요 개발 기능 (모바일 메신저 연계)**
    
    - **사용자 맞춤형 연차 현황 조회**
        
        - 개인별 당해년도 발생 일수, 사용 일수, 잔여 일수 실시간 출력
            
        - 기등록된 미래 일자의 연차 예정 내역 조회 기능 지원
            
        - 당해년도 일자별 상세 사용 내역(개인사유 등) 피드백 제공
            
    - **부서장 전용 '조직별 연차 현황 요약' 기능**
        
        - 하위 조직원의 연차 사용 현황(발생/사용/잔여) 일괄 확인 및 모니터링 기능 구축
            
        - 그룹웨어를 사용하지 않는 현장 생산직군 데이터까지 ERP에서 통합 연동하여 누수 없는 인력 관리 지원
            
        - 조직장의 선제적인 연차 사용 독려 환경 조성으로 워라밸(Work-Life Balance) 문화 정착에 기여
            
    - **금일 조직 연차 현황 실시간 모니터링**
        
        - 당일 부서 내 연차 대상자 및 휴가계(출장, 교육 등) 정보 실시간 조회
            
        - 부재자 발생 시 부서 내 원활한 업무 대행 체계 수립에 기여
            
    - **관리자 전용 연차정보 일괄 발송 시스템 (추가 개발 완료)**
        
        - 대상자별 연차 현황 정보의 일괄 푸시(Push) 메시지 전송 기능
            
        - 일괄 발송 완료 후 총 대상, 성공/실패 여부, 소요 시간 결과 보고 기능 탑재
            
        - 매주/매월 주기별 자동 발송 스케줄러 기능 고도화

### ⑤ 보안 강화를 위한 SSO 인증방식 개발 (진행)

- **개발 개요**
    
    - 향후 개발 예정인 다양한 기간계 및 사내 웹 서비스들의 보안 로그인 환경 강화
        
    - 통합 로그인 체계 일원화를 통해 일관성 있고 편리한 인프라 지원 환경 마련
        
- **구현 및 개발 내용**
    
    - **네이버웍스(Naver Works) SSO 서비스 연계**
        
        - 기존 전사 협업 도구인 네이버웍스 계정 정보 기반의 Single Sign-On(SSO) 통합 인증 체계 개발 중 (진행률 $80\%$)
            
        - 신규 사내 개발 서비스 접근 시 개별 로그인 절차를 생략하고 네이버웍스 연동을 통해 즉시 접속할 수 있도록 구현
            
    - **인증 아키텍처 수립 및 적용**
        
        - 표준 보안 프로토콜을 적용하여 향후 점진적으로 추가될 기간계 서비스에 유연하게 확장·적용할 수 있는 공통 인증 모듈 설계 완료
            
        - 별도의 독립 인증 시스템 도입 비용 없이, 2차 인증 도입 및 보안 수준 향상 효과 기대
            
- **기대 효과**
    
    - 임직원의 다중 서비스 패스워드 설정·관리 복잡성 해소를 통한 사용자 편의성 제고
        
    - OTP 2차 인증 도입을 통한 사내 주요 보안 관리 체계 수립 및 계정 도용 위험 차단, 외부 보안 심사 적합성 등급 상향 달성 기반 마련

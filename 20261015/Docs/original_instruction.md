# [원본 지시문] 네이버웍스 조직도 담당 업무 등록 및 검색 개선 가이드

본 문서는 사용자 요청 원본 지시사항을 기록 보관한 파일입니다.

### 원본 지시 내용 (User Request)

네이버웍스 조직도내에 담당 업무를 등록하여, 사내 구성원들이 편리하게 담당업무를 검색하여 해당업무의 담당자를 찾도록 하고자 한다.
https://help.worksmobile.com/ko/use-guides/contacts/company-members/search-organization-contact/
네이버웍스 조직도 가이드문서를 참고한다.

모바일앱, PC웹, PC앱의 세가지 방법이 있는데, 담당업무가 화면에 노출되는 Default 성격은 PC앱이 가장 업무 노출성이 좋다.
모바일앱, PC웹은 사용자를 클릭해서 Detail을 통해서만 담당업무가 노출된다.
단, 세가지 모드 모든 환경에서 담당업무를 조회할수 있다.
@[images/1.png] 이미지 첨부와 같이, 한화면에 조회되는 내용은 1~2줄로 표기되다보니, 아무래도 30자정도의 키워드를 기반으로 작성되는 담당업무를 사용해야 원활히 가능할 것으로 보인다.
@[images/2.png]  PC웹 - 사용자프로필 - 개인정보 - 내프로필에서 두번째 이미지와 같은 내용을 직접 입력할수 있으며 사용자가 직접 입력하시기 바랍니다.
@[images/3.png] 담당업무의 키워드는 세번째 이미지와 같이 키워드를 통해서 검색이 가능하다.
위의 해당내용을 사용자가 이해하기 쉬운 전달 가이드의 방향으로 문서 작성하자.

문서작성시에 현재의 지시문을 Docs 폴더에 남겨 별도 원본 기록하고, Docs 폴더에는 Sample폴더의 @[sample/2026_08_it_monthly_report_content.md] 와 같이 문서의 내용을 사용자가 쉽게 입력할수 있도록 문서기반의 MD 문서를 생성한다.
해당 문서기반의 MD를 통해서 최종적으로 sample 폴더의 @[sample/2026_08_it_monthly_report.html] 와 같은 문서를 작성하도록 하는것이 목적이다.

현재의 문서는 사용자와의 업무 개선을 위한 목적을 위하여 작성되는 문서로 최대한 내용을 상세하게 작성하여 사용자가 쉽도록 이해하고, 상호간의 의견을 개선할수 있도록 하는 것을 목적으로 작성한다.

첨부된 이미지를 활용하고 공식 문서내의 참고내용도 포함하여 네이버웍스 조직도를 이용한 담당 업무를 등록하여, 사내 구성원들이 편리하게 담당업무를 검색하는 것을 개선하도록 제안하자.

작성된 MD 파일을 통해서 추후 내용을 수정할수 있도록 지원해라.

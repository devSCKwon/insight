## 1. 개요 및 핵심 업데이트 4대 하이라이트

### [카드 1] 네이버웍스 V4.6 결재 개편 방향
- **본문**: 이번 네이버웍스 V4.6 정기 업데이트(2026.07.23)에서는 결재 업무의 생산성과 연속성을 극대화하기 위해 파일 연동, 문서 진행 알림, 결재 위임 관리 체계, 그리고 Workflow Bot 기반의 챗봇 결재 승인 기능을 대폭 고도화하였습니다.
- **슬로건**: "다운로드 없는 드라이브 직접 연동부터 부재 시 상태별 결재 위임, 챗봇 원스톱 승인까지 더욱 새로워진 결재 프로세스"
- **4대 핵심 업데이트 요약**:
  1. **드라이브 파일 첨부 및 직접 저장 기능 추가**: PC 다운로드 수작업 없이 드라이브(메시지/그룹 대화방) 저장 파일을 결재/의견에 바로 첨부하고, 첨부된 파일도 드라이브 폴더로 직접 저장 가능.
  2. **결재 지연 알림 & 공유 의견 알림 대상 확대**: 5/7/10/14일 기준 결재 대기 지연 알림을 제공하고, 참조 결재자 및 공유 대상자까지 의견 알림을 확대하여 소통 공백 제거. (※ 지연 알림 기준 설정은 휴무일 이후 반영 예정)
  3. **결재 위임 설정 위치 개편**: 기존 부재 일정 작성 화면에서 '네이버웍스 상태 설정'으로 통합 이동하여, 휴가/출장 등 상태별로 결재 대리인을 각각 1명씩 독립 지정 및 관리.
  4. **Workflow Bot 신규 기능 추가**: 결재 요청 발생 시 메시지방에 Bot 채널이 자동 생성되어, 앱 이동 없이 챗봇 메시지 내에서 실시간 결재 확인 및 즉시 승인/반려 가능.

## 2. 세부 기능별 사용자 가이드

### ① 드라이브 파일 첨부 및 저장 기능 추가
- **[핵심 효과]**: 이중 다운로드 공수 제거 및 업무 파일의 드라이브 일관 관리
- **본문**: 결재 문서 작성 및 공유 의견 등록 시, PC에 있는 파일뿐만 아니라 네이버웍스 드라이브(메시지/그룹 대화방내 폴더)에 저장된 파일도 즉시 선택하여 첨부할 수 있습니다. 또한 수신한 결재 문서의 첨부파일을 PC에 다운로드하지 않고 드라이브 지정 폴더에 바로 저장할 수 있습니다.
- **세부 안내 내용**:
  - **드라이브 파일 직접 첨부**: 결재 문서 기안 시 [드라이브에서 선택] 버튼을 통해 파일 업로드 가능 (공유 의견 작성 시에도 동일 적용).
  - **첨부파일 드라이브 바로 저장**: 수신한 결재 문서의 첨부파일 옆 [드라이브에 저장] 버튼을 클릭하여 원하는 업무 폴더로 직행 저장.

  - **제목**: [시스템 화면] 결재 작성 시 드라이브 파일 첨부
  - **설명**: 결재 문서 작성(기안) 시 네이버웍스 드라이브에서 직접 저장된 업무 파일을 선택하여 첨부하는 화면입니다.
- **[이미지 1-2] 기능 화면 (공유 의견 작성 시 드라이브 파일 첨부)**:

  - **설명**: 결재 수신 문서 또는 참조 문서의 공유 의견 작성 시 드라이브 내 파일을 즉시 첨부하는 화면입니다.
- **[이미지 1-3] 기능 화면 (대화방 폴더 연동 및 업무 파일 공유)**:

  - **설명**: 드라이브로 지정된 파일은 내가 속한 메시지방(개별 메시지, 그룹 대화방) 내의 공유 폴더를 이용하게 되므로, 팀원들과 업무 공유 및 파일 전달이 편리한 화면입니다.

### ② 결재 지연 문서 알림 추가 및 공유 의견 알림 개선
- **[핵심 효과]**: 결재 병목 현상 방지 및 공유/참조자 소통 알림 강화
- **본문**: 결재 문서가 일정 기간 이상 대기 상태에 머무를 경우 결재자에게 자동으로 지연 알림이 발송되며, 문서에 새로운 공유 의견이 등록되면 작성자/승인자 외에도 참조 결재자와 공유 대상자에게까지 알림이 확대 발송됩니다.
- **세부 안내 내용**:
  - **지연 알림 기준 기간 설정**: 결재 대기 지연 알림 기준을 5일, 7일, 10일, 14일 중에서 조직 운영 방침에 맞추어 자유롭게 선택 설정 가능하도록 변경 / 코어 업데이트가 완료되지 않아 아직 미적용 상태이나 휴무일 이후에 즉각 반영 예정입니다.
  - **공유 의견 알림 대상 확대**: 직접 승인 결재를 진행하지 않는 참조 결재자(참조자) 및 단순 공유 대상자도 실시간 의견 등록 톡/메일 알림을 수신하여 즉각적인 이력 파악 지원.
  - **관리자/문서 설정 유의사항**: 관리자가 고정한 필수 알림 항목은 개인이 임의 해제할 수 없으며, 특정한 개별 문서에서 알림을 끈 경우 해당 문서의 알림만 제외됩니다.
- **[이미지 2-1] 기능 화면 (결재 지연 문서 알림 설정)**:
  - **제목**: [시스템 화면] 결재 지연 문서 알림 설정 (5/7/10/14일)
  - **설명**: 일정 기간 이상 결재 대기 중인 문서를 알림으로 안내하여 누락을 방지합니다. 지연 알림은 5일, 7일, 10일, 14일 중에서 원하는 기준으로 자유롭게 선택 설정할 수 있습니다.
- **[이미지 2-2] 기능 화면 (참조자 및 공유 대상자 알림 확대)**:
  - **제목**: [시스템 화면] 참조자 및 공유 대상자 알림 확대
  - **설명**: 문서에 새로운 공유 의견 등록 시 작성자/승인자 외에도 참조 결재자와 공유 대상자까지 알림이 확대 발송되어, 직접 결재를 안 하는 구성원도 문서 진행 상황을 쉽게 파악할 수 있습니다.

### ③ 결재 위임 관리 위치 개편 (네이버웍스 상태 설정 통합)
- **[핵심 효과]**: 부재 일정과 결재 위임의 독립 관리 및 상태별 맞춤 대리인 지정
- **본문**: 기존 부재 일정 작성 화면에 포함되어 있던 결재 위임 설정이 프로필 내 '네이버웍스 상태 설정' 메뉴로 통합 이동되었습니다. 이제 휴가, 출장, 외근 등 자리를 비우는 개별 상태에 맞춰 결재 대리인을 독립적으로 지정할 수 있습니다.
- **세부 안내 내용**:
  - **상태 설정을 통한 독립 관리**: 부재 일정 입력과 별개로 네이버웍스 상단의 상태 설정(휴가 중, 출장 중 등)에서 직접 결재 대리인 지정.
  - **상태별 대리인 지정 (최대 1명)**: 설정된 각 상태별로 결재 대리인을 1명씩 지정할 수 있으며, 설정 완료 시 관련 서비스 알림 및 대리 권한이 자동 부여됨.
  - **접근 경로 안내**:
    - **경로 1**: PC/모바일 우측 상단 `프로필 사진` > `상태 설정` 클릭
    - **경로 2**: `환경 설정` > `개인 정보` > `상태 설정` 이동
  - **부재 일정 화면 안내 문구**: 기존 부재 일정 작성 화면 진입 시 결재 위임 설정 이동 안내 링크가 자동으로 노출됩니다. (※ 경영지원 상품 이용 시 표출)
- **[이미지 3-1] 기능 화면 (프로필 상태 설정 내 결재 대리인 지정)**:
  - **제목**: [시스템 화면] 상태 설정 내 결재 대리인 지정 및 경로
  - **설명**: 결재 대리인은 상태별로 1명까지 설정할 수 있으며, 설정 완료 시 서비스 알림이 발송됩니다. 상태 설정은 우측 상단 프로필 사진 > 상태 설정 또는 환경 설정 > 개인 정보 > 상태 설정에서 가능합니다.
- **[이미지 3-2] 기능 화면 (대리인 지정 상세 및 위임 기간 설정)**:
  - **제목**: [시스템 화면] 대리인 상세 설정 및 위임 기간 지정
  - **설명**: 상세 설정 화면을 통해 대리인(위임자) 지정 시 시작/종료 기간을 함께 설정하여 부재 중 결재 누락 및 업무 지연을 방지합니다.

### ④ Workflow Bot 신규 기능 추가 (실시간 결재 챗봇 알림 & 원스톱 승인)
- **[핵심 효과]**: 결재 앱 이동 없는 메시지방 봇 채널 실시간 확인 및 즉시 승인/반려
- **[중요 권장 유의사항]**: Workflow Bot 메시지방을 통한 승인/반려는 빠른 원스톱 처리가 가능하지만, 결재 문서의 세부 첨부파일 및 상세 내용을 정밀하게 확인해야 하는 경우에는 **반드시 [문서보기]를 클릭하여 원본 결재 문서를 확인한 후 승인/반려를 진행**해 주시기 바랍니다.
- **본문**: 처리해야 할 결재 문서가 생기면 메시지방에 **Workflow Bot** 채널이 자동으로 생성되어 알림이 발송됩니다. 별도로 결재 서비스 화면으로 이동할 필요 없이, 메시지 톡 화면 내에서 결재 요청 문서를 확인하고 즉시 [승인] 또는 [반려]를 완료할 수 있습니다.
- **세부 안내 내용**:
  - **무설치 자동 채널 생성**: Workflow Bot은 별도의 앱 다운로드나 추가 설치 없이 사용할 수 있으며, 결재 요청이 발생하면 메시지방에 봇 채널이 자동으로 생성됩니다.
  - **메시지방 원스톱 승인/반려**: 메시지 톡 화면 내에서 결재 문서 요약을 확인하고 클릭 한 번으로 승인 및 반려 처리를 완결할 수 있어 업무 속도가 대폭 향상됩니다.
- **[이미지 4-1] 기능 화면 (Workflow Bot 결재 알림 및 원스톱 승인/반려)**:
  - **제목**: [시스템 화면] Workflow Bot 결재 알림 및 원스톱 승인/반려
  - **설명**: 처리해야 할 결재가 생기면 Workflow Bot으로 알림이 발송됩니다. Bot에서 결재 요청 내용을 확인하고 즉시 승인 또는 반려 처리할 수 있습니다. Workflow Bot은 별도 설치 없이 사용할 수 있으며, 결재 요청이 발생하면 Bot 채널이 메시지방에 자동으로 생성됩니다.

## 4. 관련 참고 링크

### 💡 사용자 권장 수행 과제
1. **Workflow Bot 확인**: 메시지방에 결재 요청 시 자동 생성되는 Workflow Bot 채널을 확인하고 메시지를 통한 빠른 승인 기능을 활용하세요.
2. **상태 설정 체크**: 우측 상단 프로필 사진 > [상태 설정]을 클릭하여 부재 시 적용할 상태별 결재 대리인 지정 상태를 사전 확인하세요.
3. **드라이브 저장 활용**: 수신 문서 내 중요한 첨부파일은 [드라이브에 저장] 기능을 활용하여 팀 공유 폴더로 안전하게 관리하세요.
4. **지연 알림 설정**: 결재 대기 문서 지연 기준(예: 5일 또는 7일)을 환경 설정에서 점검하세요.

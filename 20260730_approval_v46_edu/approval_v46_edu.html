그룹웨어(네이버웍스) V4.6 업데이트에 따른 사용자 가이드

"더욱 편리하고 똑똑해진 결재 업무 환경 및 핵심 기능 총정리"

작성일: 2026년 7월 30일 반영일: 2026년 7월 23일 (정기 업데이트)
V4.6 결재 개편 핵심 요약

이번 네이버웍스 V4.6 정기 업데이트(2026.07.23)에서는 결재 업무의 생산성과 연속성을 극대화하기 위해 파일 연동, 문서 진행 알림, 결재 위임 관리 체계, 그리고 Workflow Bot 기반의 챗봇 결재 승인 기능을 대폭 고도화하였습니다.

"다운로드 없는 드라이브 직접 연동부터 부재 시 상태별 결재 위임, 챗봇 원스톱 승인까지 더욱 새로워진 결재 프로세스"

1. 드라이브 연동 강화

결재 작성 시 드라이브 파일 직접 첨부 & 수신 첨부파일 PC 저장 없이 드라이브 폴더로 바로 저장 지원.

2. 알림 체계 고도화

5/7/10/14일 기준 결재 지연 알림 발송 및 참조 결재자, 공유 대상자까지 공유 의견 실시간 알림 확대.

3. 결재 위임 개편

네이버웍스 프로필 상태 설정으로 통합되어 휴가/출장 등 상태별 맞춤 결재 대리인(1명) 독립 지정 가능.

4. Workflow Bot 연동

결재 요청 발생 시 메시지방 Workflow Bot 자동 생성 및 메시지 봇 화면에서 즉시 승인/반려 가능.

① 드라이브 파일 첨부 및 저장 기능 추가

드라이브 직접 선택 첨부 & 바로 저장

이중 다운로드 공수 절감

결재 문서 작성 및 공유 의견 등록 시, PC에 있는 파일뿐만 아니라 네이버웍스 드라이브(메시지/그룹 대화방내 폴더)에 저장된 파일도 즉시 선택하여 첨부할 수 있습니다. 또한 수신한 결재 문서의 첨부파일을 PC에 다운로드하지 않고 드라이브 지정 폴더에 바로 저장할 수 있습니다.

  • 드라이브 파일 직접 첨부: 결재 문서 기안 시 [드라이브에서 선택] 버튼을 통해 파일 업로드 가능 (공유 의견 작성 시에도 동일 적용).
  • 첨부파일 드라이브 바로 저장: 수신한 결재 문서의 첨부파일 옆 [드라이브에 저장] 버튼을 클릭하여 원하는 업무 폴더로 직행 저장.

② 결재 지연 문서 알림 추가 및 공유 의견 알림 개선

결재 지연 알림 & 공유 의견 알림 대상 확대

실시간 소통 강화

결재 문서가 일정 기간 이상 대기 상태에 머무를 경우 결재자에게 자동으로 지연 알림이 발송되며, 문서에 새로운 공유 의견이 등록되면 작성자/승인자 외에도 참조 결재자와 공유 대상자에게까지 알림이 확대 발송됩니다.

  • 지연 알림 기준 기간 설정: 결재 대기 지연 알림 기준을 5일, 7일, 10일, 14일 중에서 조직 운영 방침에 맞추어 자유롭게 선택 설정 가능하도록 변경 / 코어 업데이트가 완료되지 않아 아직 미적용 상태이나 휴무일 이후에 즉각 반영 예정입니다.
  • 공유 의견 알림 대상 확대: 승인 결재를 직접 하지 않는 참조 결재자(참조자) 및 공유 대상자도 실시간 의견 등록 톡/메일 알림을 수신하여 즉각적인 이력 파악 지원.
  • 관리자/문서 설정 유의사항: 관리자가 고정한 필수 알림 항목은 개인이 임의 해제할 수 없으며, 특정한 개별 문서에서 알림을 끈 경우 해당 문서의 알림만 제외됩니다.

③ 결재 위임 관리 위치 개편 (상태 설정 통합)

네이버웍스 상태 설정 통합 & 독립 대리인 관리

부재 시 승인 연속성 확보

기존 부재 일정 작성 화면에 포함되어 있던 결재 위임 설정이 프로필 내 '네이버웍스 상태 설정' 메뉴로 통합 이동되었습니다. 휴가, 출장, 외근 등 자리를 비우는 개별 상태에 맞춰 결재 대리인을 독립적으로 지정할 수 있습니다.

  • 상태 설정을 통한 독립 관리: 부재 일정 입력과 별개로 네이버웍스 상단의 상태 설정(휴가 중, 출장 중 등)에서 직접 결재 대리인 지정.
  • 상태별 대리인 지정 (최대 1명): 설정된 각 상태별로 결재 대리인을 1명씩 지정 가능하며 완료 시 서비스 알림 자동 발송.
  • 접근 경로 안내:
      • 경로 1: PC/모바일 우측 상단 프로필 사진 > 상태 설정 클릭
      • 경로 2: 환경 설정 > 개인 정보 > 상태 설정 이동
  • 부재 일정 안내 링크: 기존 부재 일정 작성 화면 진입 시 상태 설정 이동 안내 팝업/링크 표출 (경영지원 상품 연동).

④ Workflow Bot 신규 기능 추가 (실시간 결재 챗봇 승인)

메시지방 Workflow Bot 결재 알림 및 원스톱 승인/반려

챗봇 원스톱 처리
권장 유의사항: Workflow Bot을 이용하면 메시지방에서 신속한 결재 승인이 가능하지만, 결재 문서의 세부 내용 및 첨부파일을 정밀하게 검토해야 하는 경우에는 반드시 [문서보기] 버튼을 클릭하여 원본 결재 문서를 확인한 후 승인/반려를 진행해 주시기 바랍니다.

처리해야 할 결재 문서가 생기면 메시지방에 Workflow Bot 채널이 자동으로 생성되어 알림이 발송됩니다. 별도로 결재 서비스 화면으로 이동할 필요 없이, 메시지 톡 화면 내에서 결재 요청 문서를 확인하고 즉시 [승인] 또는 [반려]를 완료할 수 있습니다.

  • 무설치 자동 채널 생성: Workflow Bot은 별도의 앱 다운로드나 설치 과정 없이 결재 요청이 발생하면 메시지방에 봇 채널이 자동으로 생성됩니다.
  • 메시지방 원스톱 승인/반려: 메시지 톡 화면 내에서 결재 문서 요약을 확인하고 클릭 한 번으로 승인 및 반려 처리를 완결하여 업무 속도를 향상시킵니다.

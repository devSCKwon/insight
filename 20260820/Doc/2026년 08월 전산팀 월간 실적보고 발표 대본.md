## [주제 1] 보안 강화를 위한 SSO 인증방식 개발

**[주제] 네이버웍스 연동 및 2차 OTP 인증을 통한 로그인 일원화 및 계정 탈취 리스크 원천 차단**

첫 번째 발표 주제인 **'보안 강화를 위한 SSO(Single Sign-On) 인증방식 개발'** 실적입니다. 현재 목표 대비 **80%의 진행률**로 순조롭게 개발 및 검증을 이어가고 있습니다.

*   **① OAuth 2.0 표준 기반의 네이버웍스 간편 인증 연동**
    *   사내에 여러 웹 시스템이 늘어남에 따라 사용자들의 다중 로그인 번거로움과 개별 비밀번호 관리에 따른 계정 노출 리스크가 상존해 왔습니다.
    *   이를 해결하기 위해 대중적인 "카카오톡으로 로그인하기"와 유사한 **OAuth 2.0 국제 표준 기술**을 적용하여, 임직원이 별도의 비밀번호 입력 없이 사내 협업 툴인 **네이버웍스(Naver Works) 세션을 기반으로 원클릭 간편 로그인**이 가능하도록 개발하였습니다.
*   **② 모바일 OTP 2차 추가 보안 인증 체계 구축**
    *   단순 간편 로그인에 그치지 않고, 관리자 계정이나 중요 기간계 접근 시에는 구글 OTP 등 모바일 OTP를 통한 **2차 추가 보안 인증을 팝업 형태로 강제 적용**하여 2중 보안 장치를 완성하였습니다.
    *   이를 통해 외부로부터의 무단 계정 도용 및 피싱 리스크를 획기적으로 완화하였습니다.
*   **③ 전산자산관리시스템 선제 시범 적용 및 세션 상속 검증 완료**
    *   현재 전산팀 내부에서 시범 운영 중인 **'전산자산관리시스템'에 SSO 모듈을 선제 적용**하여 1차 및 2차 인증, 로그인 성공 후 안전한 세션 유지, 그리고 접속 IP 및 연동 토큰 등의 감사 로그가 정상 적재되는 전 과정을 완벽히 검증 완료하였습니다.
*   **④ 고가 솔루션 도입 없는 자체 개발로 투자 비용 제로화**
    *   외부의 유료 SSO 솔루션을 도입할 경우 수천만 원의 라이선스 및 유지보수 비용이 발생하지만, 전산팀은 기존에 운영 중인 그룹웨어와 네이버웍스의 인증 인프라를 직접 연동 설계하여 **추가 비용이 전혀 발생하지 않는 고효율 보안 체계를 구현**하였습니다.

## [주제 2] 사내 Windows 서버 통합 제어 환경 구축 (WAC)

**[주제] 무분별한 RDP 노출 차단과 유휴장비 활용 WAC 게이트웨이 구축으로 인프라 보안성 및 운영 효율 극대화**

두 번째 주제인 **'사내 Windows 서버 통합 제어 환경 구축 (WAC)'** 실적입니다. 전사 Windows 서버군의 원격 관리 보안을 중앙 집중화하는 과제로, 현재 **80%의 진행률**을 보이고 있습니다.

*   **① 개별 서버 RDP(원격 데스크톱) 및 직접 IP 포트 접근 전면 차단**
    *   기존에는 각 Windows 서버마다 원격 데스크톱(RDP 3389 포트)이 개방되어 있어, 내부망 침투 시 무차별 대입 공격(Brute Force)이나 랜섬웨어의 횡적 전파에 노출될 위험이 있었습니다.
    *   이에 따라 모든 Windows 서버의 직접적인 IP 및 RDP 접근을 원천 차단하고, 오직 **WAC(Windows Admin Center) 보안 서버의 단일 웹 제어 인터페이스를 통해서만 중앙 통제**되도록 서버군별 포트 제어 설정을 단계적으로 적용하고 있습니다.
*   **② 외부 접속 통제 현황 및 향후 웹 SSL 1차 인증 검토**
    *   현재 외부 환경에서의 관리는 **SSL VPN을 통해 인가된 관리자만 안전하게 접근**할 수 있도록 통제 체계를 운영 중입니다.
    *   이에 더해 향후 웹 브라우저를 통한 보안서버 진입 시 강력한 자체 SSL 암호화 인증을 거치도록 하는 1차 접근 제어 장치 도입을 함께 검토하고 있습니다.
*   **③ 기능별 최소 권한(RBAC) 통제 및 다중 로그인 강제**
    *   관리자에게 서버 전체의 전지전능한 권한을 부여하는 대신, 작업 목적에 부합하는 최소 권한만을 기능별로 세분화하여 부여하고 있습니다.
    *   또한 위험도가 높은 설정 변경이나 주요 명령어 수행 직전에는 **대상 서버의 로그인을 다시 한번 강제하는 다중 인증 제어**를 적용하여 권한 오남용을 방지하고 책임성을 강화하고 있습니다.
*   **④ 사내 유휴장비 재활용을 통한 예산 절감**
    *   고가의 외산 서버 통합 관리 솔루션을 별도로 구매하지 않고, **사내 유휴 서버 장비에 WAC 게이트웨이 환경을 직접 설계 및 구축**하여 유휴 자원의 가치를 극대화하고 도입 비용을 완전히 절감하였습니다.

## [주제 3] 08월 중점 과제 도입 기대효과

**[주제] 개인정보 유출 방어, 랜섬웨어 차단, 비용 절감 및 운영 생산성 혁신의 4대 기대 성과**

이어서 이번 8월 중점 과제들이 현업에 완전히 안착되었을 때 회사가 얻게 되는 주요 기대효과를 보고드리겠습니다.

*   **[SSO 통합 인증 도입 기대효과]**
    1.  **개인정보 유출 및 보안사고 원천 예방**: 개별 시스템마다 사용자 계정과 비밀번호를 분산 저장·관리할 때 발생하는 데이터 유출 취약점을 단일 표준 인증 체계로 사전에 방어합니다.
    2.  **검증된 대외 SaaS(Naver Works) 인프라 신뢰성 활용**: 국내 최고 수준인 네이버의 보안 인프라를 활용하여 별도 비용 없이 엔터프라이즈급 개인정보 보호 체계를 확립합니다.
    3.  **입·퇴사자 계정 라이프사이클 원스톱 통제**: 그룹웨어 계정과 1:1 연동되므로, 퇴사나 휴직 발생 시 그룹웨어 계정 정지만으로 사내 모든 연동 시스템의 접근 권한이 즉시 회수되어 퇴사자 계정 도용 및 정보 유출을 완벽히 차단합니다.
    4.  **시스템 개발 및 유지보수 비용 절감**: 향후 신규 웹 시스템 개발 시 개별 로그인 기능을 중복 개발할 필요 없이 표준 SSO 공통 모듈만 탑재하여 개발 기간과 비용을 대폭 줄일 수 있습니다.

*   **[Windows 서버 WAC 통합 제어 도입 기대효과]**
    1.  **RDP 포트 차단 및 랜섬웨어 침투 봉쇄**: 취약한 RDP 포트를 전면 폐쇄하고 외부 SSL VPN 및 WAC 단일 웹 채널로 통제하여 외부 침해 및 랜섬웨어 전파 경로를 원천 차단합니다.
    2.  **유휴장비 재활용을 통한 투자 예산 절감**: 신규 솔루션 구매 없이 사내 유휴 서버를 재활용하여 하드웨어 자원 효율화와 비용 절감(도입 비용 0원)을 동시에 달성합니다.
    3.  **기능별 최소 권한 통제와 관리 책임성 확보**: 작업 목적에 맞는 최소 권한 부여와 위험 작업 전 다중 로그인을 통해 관리자 권한 오남용을 방지하고 명확한 작업 추적성을 확보합니다.
    4.  **웹 기반 중앙 통제를 통한 서버 관리 생산성 극대화**: 전사 Windows 서버군의 상태 모니터링, 이벤트 로그, 서비스 관리 등을 단일 웹 화면에서 일괄 제어함으로써 전산팀의 관리 공수를 획기적으로 절감합니다.
